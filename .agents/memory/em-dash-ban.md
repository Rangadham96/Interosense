name: Em dash ban
description: Em dashes (—) are permanently banned from all user-facing text in Interosense. Applies everywhere including legal pages, completion screens, banners, tooltips, and any string a user can read.
---

# Rule
Never write the em dash character (—) in any user-facing text, copy, or string.

**Why:** The owner finds em dashes look AI-generated and unnatural. They break the "everyday language" tone that is core to the brand.

**How to apply:**
- Replace "X — Y" with "X. Y" (new sentence) or "X, Y" (comma) or "X: Y" (colon) depending on context.
- Legal pages, privacy policy, terms — same rule applies.
- Null/placeholder values in UI (e.g. no data yet): use "-" (hyphen) not "—".
- Code comments that are never rendered to users are exempt, but prefer clean language anyway.
- Before writing any new copy, run a mental check: does this contain —? If yes, rewrite it.
